# Confluxa - Event Management Platform

![Confluxa Banner](https://i.ibb.co.com/N06jY4c/event1.jpg)

## Overview

Confluxa is a full-stack event management platform where users can explore events, view event details, book events, and manage their activities through a personalized dashboard.

The project demonstrates modern frontend and backend architecture with TypeScript, secure authentication, RESTful API design, database management, responsive UI, and reusable component-based development.

## Features

### User Features

- Browse upcoming events
- Search and filter events
- View detailed event information
- Add events to personal dashboard
- Manage booked events
- Secure authentication system
- Responsive user interface


### Organizer Features

- Create new events
- Manage created events
- View event information
- Control event status


### Authentication & Security

- Email/password authentication
- JWT based API protection
- Protected routes
- Role-based authorization
- Secure server-side validation
